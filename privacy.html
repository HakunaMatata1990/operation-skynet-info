About the Application

Operation Skynet is a personal desktop application used to retrieve sports schedules and create events in the owner's Google Calendar.

Information Accessed

Operation Skynet uses Google OAuth authorization to access the owner's Google Calendar for the purpose of managing sports schedule events.

How Information Is Used

Google Calendar access is used solely for the application's personal scheduling functions.

Data Storage

The application operates locally on the owner's computer. Google OAuth credentials and authorization tokens are stored locally and are not published on this website.

Data Sharing

Operation Skynet does not sell Google user data or provide a public service for collecting other users' information.

Access and Revocation

The Google account owner can revoke the application's access through their Google Account security settings.

Website

This website provides information about Operation Skynet. It does not provide public account registration.
